# Research Notes

Thư mục này chứa note nghiên cứu có cấu trúc cho từng quy tắc hoặc nhóm quy tắc.

## Quy tắc

- Một note không đồng nghĩa với một implementation.
- Chỉ mục có trạng thái VERIFIED mới được dùng để viết production logic.
- Mỗi note phải chỉ rõ bản Việt, Hán bản, điểm khớp/khác và oracle nếu có.
- Không chép dài nguyên văn sách; chỉ lưu phần cần thiết để xác minh logic.

## Tên file

Dùng English, kebab-case theo convention repo.

Ví dụ:

- solar-term-month-boundary.md
- twelve-officers.md
- month-break.md
- heavenly-virtue.md

Nội dung bên trong dùng thuật ngữ nghiệp vụ tiếng Việt.
